# 森林植物风摆序列 ImageGen 记录

版本：`plant-wind-v2`  
生成器：Codex 内置 ImageGen  
模式：`identity-preserve`

正式运行时单株 PNG 作为身份参考，每种植物生成一张 2×2 四帧表：

1. 接近中心、轻微左倾；
2. 枝叶或花茎向右弯曲；
3. 回到中心并产生局部叶片/花瓣形变；
4. 枝叶或花茎向左弯曲。

公共约束：

- 四格必须保持相同缩放、相同根部接地点和相同水彩墨线风格。
- 变化必须来自树冠、叶簇、菌盖、花茎、花瓣或草叶的重新绘制，
  禁止将整张图片刚性旋转。
- 背景为纯 `#FF00FF`，无网格线、文字、阴影、地面和附加物。
- 帧 3 返回帧 0 时必须形成可循环的柔和风摆。

覆盖 `conifer`、`bush`、`mushrooms`、`flowers`、`lavender` 五类植物。
本地流水线将每帧缩回原植物纹理尺寸并锁定底部基线，运行时使用
`0→2→1→2→3→2` 的缓动播放顺序以及实例错相。
