# 八角色专属水泡 ImageGen 记录

版本：`bubbles-v3`  
生成器：Codex 内置 ImageGen  
模式：`identity-preserve`

每只动物均以正式 `idle_down.png` 为身份与画风参考，生成一张居中的
ImageGen 水泡原图。公共约束如下：

- 单个接近圆形的肥皂泡，手绘墨线、水彩纸纹、粗外轮廓。
- 主体约占方形画布 82%，背景固定为纯 `#FF00FF`。
- 大面积可换队色区域固定使用 `#00B7C7`。
- 固定高光、墨线和物种标记不参与队色替换。
- 禁止文字、水印、额外水泡、角色全身、写实玻璃与 3D 渲染。

物种差异：

| ID | 固定识别元素 |
| --- | --- |
| `cat` | 猫耳、三道额纹、胡须、卷尾纹 |
| `dog` | 垂耳、鼻塞、奶油口鼻斑、弯尾纹 |
| `rabbit` | 长兔耳、粉鼻塞、圆尾球 |
| `bear` | 圆耳、棕色口鼻斑、灰色爪印 |
| `fox` | 尖耳、橙白脸纹、灰尾尖的卷尾纹 |
| `raccoon` | 尖耳、黑色眼罩带、灰白环尾纹 |
| `penguin` | 小鳍、橙色喙塞、白肚斑、冰晶高光 |
| `capybara` | 圆耳、椭圆口鼻徽记、棕色毛斑、顶叶 |

本地确定性流水线负责色键抠图、队色遮罩提取和统一 `512×512`
落地基线；运行时原图及遮罩位于
`assets/art/storybook25d/effects/character_bubbles/`。
