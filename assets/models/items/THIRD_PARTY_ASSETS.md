[Kenney Platformer Kit](https://kenney.nl/assets/platformer-kit), version 4.1.

Selected source files:

- `Models/GLB format/spring.glb` → speed pickup
- `Models/GLB format/star.glb` → power pickup
- `Models/GLB format/bomb.glb` → bubble-capacity pickup
- `Models/GLB format/Textures/colormap.png` → shared model palette
